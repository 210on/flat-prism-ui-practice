# Flat Prism UI Practice

フラットな形と控えめなガラス感、操作に応えるプリズム色を組み合わせたUIの練習用キットです。ボタン、入力欄、タブ、文字スタイルなどの状態を、ライト・ダーク両テーマで確認できます。

## プレビュー

`preview.html`をブラウザで開いてください。ビルドや外部ライブラリは不要です。表示される名前、ドメイン、カードは架空の見本です。ボタンの保存処理も見た目を確認するための模擬動作です。

## ファイル

- `preview.html`：単体で開ける状態カタログ。CSSとJSを内包。
- `prism-ui.css`：既存サイトへ導入するためのスコープ付きスタイル。
- `prism-ui.js`：選択、タブ、操作反応などの任意の補助コード。
- `DESIGN.md`：デザインルール、API、既存プロジェクトへの対話的な導入手順。

## 既存プロジェクトへ導入する場合

[DESIGN.md](DESIGN.md)の「既存プロジェクトへの導入」を先に読んでください。既存のブランド色、部品、操作と競合する箇所は、現状と変更案を並べたモックで比較し、導入する人の判断を確認してから実装します。CSSは`.prism-ui`内を対象とし、JSの採用は必要な機能だけで構いません。

このリポジトリはUIモックおよび設計例です。プレビュー内の見本は実サービスへの送信・保存を行いません。
